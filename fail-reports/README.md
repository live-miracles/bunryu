# Fail reports

Incident write-ups, one file per incident, written with the
`write-fail-report` skill (`skills/write-fail-report/SKILL.md`).

The project was called **restream-srs** until 2026-10-14, when it was renamed
to Bunryu. Reports from before the rename are kept as written: they quote the
names in use at the time (`/opt/restream-srs`, `/var/lib/restream-srs`,
`/etc/restream-srs`, `restream-srs.service`, `restream.json`), which are now
`/opt/bunryu`, `/var/lib/bunryu`, `/etc/bunryu`, `bunryu.service` and
`bunryu.json`.
